# MultiSSGeneral population-decay example

`Tobias_Gross_population_decay_template.msd` is a **runnable template**, not a parameterization of a specific experiment. Every numerical rate and field marked `DEMO VALUE` must be replaced before scientific use.

## What the template computes

The represented state is a direct sum of the density operators of `S0`, `S1`, and `CSS`. `S0` and `S1` each retain an explicit spin-1 `N1` memory degree of freedom, while `CSS` contains two electron spins plus the same nuclear spin. The finite optical pump is an incoherent Gaussian transfer rate. Reversible `S1 <-> Singlet-CSS` transfer uses `preservespins=N1`, so the map is the identity on `N1` and therefore preserves both nuclear populations and coherences.

The CSS singlet and triplet States are projectors/subspaces inside **one** CSS SpinSystem. In a quantum CSS calculation, singlet-triplet conversion should normally be generated by the CSS Hamiltonian and relaxation model. Do not add an independent classical `k_ST` on top of that dynamics unless you intentionally select a reduced kinetic model.

The output contains columns such as:

- `s0.population`, `s1.population`, `css.population`
- `css.singlet.population`, `css.t0.population`, ...
- per-transition instantaneous fluxes when `transitionfluxes=true`

For fluorescence comparison, the updated template exposes a dedicated `Fluorescence` sink, so `s1.fluorescence.flux = k_F P_S1(t)` is the direct primitive observable (and can be convolved with the instrument response afterwards).

The updated template uses spherical (`ops=0`) Nakajima-Zwanzig rotational modulation for g-tensor anisotropy and anisotropic hyperfine fluctuations. For isotropic rotational diffusion the six `def_g=1` factors are `0,G,G,G,G,G`: rank 0 is rotationally invariant and the five rank-2 channels share the same rotational correlation. The numerical factors are synthetic and must be replaced by values derived from the real tensors.

With the MultiSS Krylov update, `propagationmethod=krylov` applies the existing sparse Arnoldi/Krylov exponential action to each event-aware time interval. This avoids the conditional-stability restriction of fixed-step RK4; `timestep` still has to resolve a finite Gaussian rate profile.

## `preservespins` is not a pulse-selection keyword

`preservespins=N1` means that `N1` is **unaffected** by that kinetic transfer. Conceptually,

```text
C = C_active (x) I_N1
```

so an arbitrary nuclear density matrix, including off-diagonal coherence, is carried into the destination manifold. A spin actually driven by an RF/MW magnetic pulse belongs to magnetic-drive Hamiltonian/pulse machinery; it is not listed under `preservespins` for that reason.

## Gaussian optical pulse

For

```text
rateprofile = gaussian;
pulsecenter = t0;
pulsefwhm = tau;
transferfraction = f;
```

MultiSSGeneral uses

```text
k(t) = k_peak exp[-4 ln(2) (t-t0)^2/tau^2]
```

with `k_peak` chosen such that an isolated one-way supported population obeys `f=1-exp[-integral k(t)dt]`. Alternatively supply `peakrate` instead of `transferfraction`. A finite Gaussian optical-rate treatment has precedent in solid-state/NV rate-equation modeling (DOI `10.1038/ncomms14000`). The delta-pulse/event limit is motivated by the pump/push treatment in DOI `10.1126/science.abl4254`.
